## 🖼️ Logo 设计 Prompt

### Grok Imagine Prompt (英文)

```
Design a modern, minimalist logo for "RadioClaw" - an AI assistant for radiolarian research. 

Main elements:
- A stylized radiolarian fossil (siliceous skeleton with intricate lattice pattern)
- Integrated with a subtle AI/tech element (circuit lines or neural network pattern)
- Color scheme: Deep ocean blue (#1a5276) + Silicon white (#ecf0f1) + Accent gold (#f4d03f)
- Clean, scientific, professional look
- Should work well at small sizes (app icon) and large sizes (conference banner)
- Include both icon-only version and horizontal version with text "RadioClaw"

Style references:
- Modern biotech company logos
- Scientific journal branding
- Clean tech startup aesthetics

Avoid:
- Too many details that won't scale
- Generic AI brain icons
- Cartoon-style illustrations
```

### Grok Imagine Prompt (中文增强版)

```
为"RadioClaw"设计一个现代简约的标志 - 这是一个放射虫研究 AI 助手。

主要元素：
- 风格化的放射虫化石（硅质骨骼，精致的格子状图案）
- 融入微妙的 AI/科技元素（电路线条或神经网络图案）
- 配色方案：深海蓝 (#1a5276) + 硅质白 (#ecf0f1) + 点缀金 (#f4d03f)
- 干净、科学、专业的外观
- 应该在小尺寸（应用图标）和大尺寸（会议横幅）都能良好呈现
- 包含仅图标版本和带文字"RadioClaw"的横向版本

风格参考：
- 现代生物科技公司标志
- 科学期刊品牌设计
- 清洁科技初创企业美学

避免：
- 过多无法缩放的细节
- 通用 AI 大脑图标
- 卡通风格插图
```

## 📐 标志变体 / Logo Variants

### 1. 主标志 / Primary Logo
- 放射虫图标 + "RadioClaw" 文字（横向排列）
- 用于网站首页、文档顶部、会议横幅

### 2. 图标版本 / Icon Only
- 仅放射虫图形
- 用于应用图标、浏览器 favicon、社交媒体头像

### 3. 单色版本 / Monochrome
- 纯黑或纯白版本
- 用于打印、传真、单色场景

### 4. 深色模式 / Dark Mode
- 深色背景适配版本
- 用于暗色主题界面

## 🖼️ 应用图标规格 / App Icon Specifications

### macOS / iOS
```
尺寸要求：
- 1024x1024 px (App Store)
- 512x512 px (macOS)
- 180x180 px (iOS)
- 120x120 px (iOS 小图标)

格式：PNG with alpha channel
圆角：自动应用（不要预加圆角）
```

### Android
```
尺寸要求：
- 512x512 px (Play Store)
- 192x192 px (xxxhdpi)
- 144x144 px (xxhdpi)
- 96x96 px (xhdpi)
- 72x72 px (hdpi)
- 48x48 px (mdpi)

格式：PNG with alpha channel
形状：自适应图标（前景 + 背景层）
```

### Web / Favicon
```
尺寸要求：
- 512x512 px (PWA)
- 192x192 px (Android Chrome)
- 180x180 px (Apple Touch Icon)
- 32x32 px (Browser Tab)
- 16x16 px (Browser Tab)

格式：PNG + ICO
```

## 🎯 使用场景 / Usage Scenarios

### 1. GitHub 仓库
- 仓库头像：图标版本（圆形裁剪）
- README 顶部：主标志（横向）
- 文档 favicon：图标版本

### 2. 学术会议
- 会议海报：主标志（右上角）
- 演讲幻灯片：主标志（每页右下角）
- 论文页眉：单色版本

### 3. 社交媒体
- Twitter/X：图标版本 + 横幅（主标志）
- LinkedIn：主标志
- Discord：图标版本

### 4. 应用程序
- macOS 菜单栏：图标版本（单色，22x22 px）
- iOS/Android 应用：应用图标
- Web 应用：favicon + PWA 图标

---

## 🚫 使用禁忌 / Don'ts

- ❌ 不要拉伸或变形标志
- ❌ 不要更改官方配色
- ❌ 不要添加阴影或渐变效果
- ❌ 不要在复杂背景上使用（添加白色底板）
- ❌ 不要旋转标志（除非特殊设计需求）
- ❌ 不要与其他标志重叠放置
