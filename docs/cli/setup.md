# `RadioClaw setup`

Initialize `~/.RadioClaw/RadioClaw.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
RadioClaw setup
RadioClaw setup --workspace ~/.RadioClaw/workspace
```

To run the wizard via setup:

```bash
RadioClaw setup --wizard
```
